# CODRU - calculator preț bilet

O singură pagină statică (`index.html`), fără date: scrii prețul comunicat în euro, apeși Enter și vezi defalcarea
(NET organizator, TVA, timbru muzical, Crucea Roșie, raport iaBilet, comision de emitere, clientul plătește).

Pagina: https://smm2424.github.io/codru-pret/

Mecanism: comunicat × 5 lei = NET organizator, taxele se pun peste. Parametrii se pot schimba din pagină („Parametri”).
Pagina nu se indexează (`noindex`).
